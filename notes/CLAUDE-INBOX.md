# Claude inbox (do not merge)

This file exists only so the "Claude inbox" draft PR has a diff. The PR stays open and is never
merged: Claude watches it, so every comment on it wakes Claude.

- Automatic: `.github/workflows/notify-claude.yml` comments here when a `grok/` PR is opened and when
  CI finishes on a `grok/` branch.
- Manual: comment `PING` (plus a line of context) to ask Claude for a status check or a review.

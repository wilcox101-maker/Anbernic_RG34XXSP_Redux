## Lessons from this chat
- A new chat needs "Approve repo push access" in Dale's opener, or `add_repo` push is refused and the chat is read-only.
- This environment has no tool to subscribe to inbox #41; read it with `gh api repos/wilcox101-maker/anbernic_rg34xxsp_redux/issues/41/comments?since=<time>`. GraphQL (`gh pr list`) is blocked; use REST.
- Merging works with Dale's standing permission; closing someone else's PR or commenting on it may still be blocked. Don't poll in loops while idle: it costs Dale usage.
- Local builds: `sudo apt-get install libsdl2-dev` first; build desktop and stock with `-DCMAKE_C_FLAGS=-Werror`; run every `test_*` and `tools/check_rules.py` before pushing.
- When reusing another agent's branch, diff it against main first: #101 carried a stale `ui.c` that deleted 344 lines.

# Branding: the mark and the boot screen

Everything that makes this build look like "RG34XXSP Redux" lives in this folder. To make your own
build, edit these files. **No code changes are needed.**

| File | What it is | How to change it |
|---|---|---|
| `boot.ini` | Boot screen settings: colours, socket/chip/label look, the label text (up to 4 lines), version line, font scale, output file | Edit in any text editor |
| `mark.pbm` | The mark drawn on the chip label: 128×128, 1-bit PBM (`1` = ink) | Replace it with your own PBM (GIMP: *Export As → .pbm*, "ASCII" or "raw"). Any size that fits the label |
| `mark.svg` | Master vector of the mark (for print, the web, regenerating the PBM) | Replace it with your own |
| `preview.png` | What the default boot screen looks like | Regenerate after changes (below) |

## Build the boot screen

```
python tools/make_bootlogo.py                 # uses branding/boot.ini, writes build/bootlogo.bmp
python tools/make_bootlogo.py --version 0.2   # set the version line
python tools/make_bootlogo.py --ini my/boot.ini --out my/bootlogo.bmp
```

Python 3 standard library only; runs on Windows, Linux and macOS. CI renders it on every push, so a
broken `boot.ini` or mark shows up as a red check. The text uses the frontend's 8×16 VGA font
(`frontend/src/font.c`), so the boot screen matches the menu.

## Rules for marks and artwork

- Use only artwork you have the right to use: your own, or openly licensed with the licence recorded
  here. **No other company's logos or trademarks** (not the device maker's, not anyone else's), including
  combinations of them, so your build doesn't look official or endorsed.
- Put the source and licence of any new artwork in this README.

## Format

`[output] format = stock-bootlogo` writes exactly the stock boot logo's format: **640×480, 24-bit,
uncompressed, bottom-up, 54-byte header, 921,654 bytes**, read from the stock image's `boot-resource`
partition (`bootlogo.bmp`) on 2026-11-13. A 640-wide screen fits the label at `font_scale = 2`.
Check any file with `python tools/make_bootlogo.py --check file.bmp`; anything that installs a boot
logo refuses a file that fails this check.
